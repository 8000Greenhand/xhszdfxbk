# 小羊森林内容样本学习与创作转译系统 v1

## 0. 系统一句话定义

本系统不是爆文收藏库、达人复盘表、官号图文生成器或资料收藏夹。

本系统是：

> 小羊森林内容样本学习与创作转译系统。

核心目的：让 AI 持续学习小红书市场内容、达人合作内容、官号内容、评论区反馈和产品资料，判断哪些内容值得学、值得学什么、能不能被小羊森林产品承接，最终转译成创作大纲、官号挂车图文或博主文字脚本。

系统主线不是“收集样本 → 展示样本 → 看分析”，而是：

```txt
输入样本
↓
判断样本有没有学习价值
↓
判断它属于什么价值类型
↓
判断能不能关联小羊森林产品
↓
判断适合转成什么创作出口
↓
生成可执行内容
```

每条样本进入系统后，不默认有价值，也不默认要复刻。

## 1. 样本池分类

每条样本必须被归入一个或多个样本池。

### 1.1 高价值复刻样本池

适合进入这个池的内容：

- 选题本身适合小羊森林。
- 用户需求明确。
- 标题、封面、结构、评论至少有一个强亮点。
- 能自然关联某个产品。
- 有机会转成官号图文或博主文字脚本。

典型结论：这条值得深拆，可转译成某产品相关的官号图文，也可改成博主口播脚本。

### 1.2 结构参考样本池

适合进入这个池的内容：

- 行业可能不相关。
- 产品承接弱或不建议承接。
- 但标题结构、封面结构、内容展开方式、信息组织方式值得借鉴。

典型结论：这条不适合直接关联小羊森林产品，但标题结构和封面信息排序值得作为形式参考。

### 1.3 评论洞察样本池

适合进入这个池的内容：

- 内容本身未必强。
- 但评论区暴露了真实需求、购买顾虑、适用问题或新选题机会。

典型结论：内容本身不值得复刻，但评论区反复问“几岁能喝”“甜不甜”，可沉淀为产品详情页、正文、置顶评论素材。

### 1.4 产品承接样本池

适合进入这个池的内容：

- 内容背后的需求和小羊森林某个产品高度相关。
- 即使它不是爆文，也能帮助判断产品应该如何进入内容。

典型结论：这条样本核心需求是孩子加餐健康替代，适合四神饮作为加餐饮品承接。

### 1.5 反面避坑样本池

适合进入这个池的内容：

- 数据不好，且能看出明确失败原因。
- 表达方式容易违规、焦虑营销、医疗化、硬蹭热点。
- 产品植入生硬。
- 选题和产品错配。
- 看起来像爆文套路，但不适合小羊森林。

典型结论：这条不建议学习，问题在于强行把产品塞进焦虑场景，容易显得功效夸大。

### 1.6 暂存观察样本池

适合进入这个池的内容：

- 信息不足。
- 数据不完整。
- 评论区未补充。
- 暂时无法判断是否有价值。

典型结论：暂存。需要补评论区或后续数据后再判断。

### 1.7 低价值 / 丢弃样本

适合归为低价值的内容：

- 没有明显学习点。
- 与小羊森林产品和用户都无关。
- 结构普通。
- 评论无有效信号。
- 不能作为反面样本。
- 继续保留只会增加噪音。

典型结论：不建议入库，丢弃。

## 2. 样本初筛模板

每条样本进入系统后，AI 先输出这一段，不直接生成稿子。

### 2.1 基本判断

- 是否值得保留：保留 / 暂存 / 丢弃
- 样本用途分类：高价值复刻 / 结构参考 / 评论洞察 / 产品承接 / 反面避坑 / 暂存观察 / 低价值丢弃
- 行业相关性：强 / 中 / 弱 / 无
- 产品相关性：强 / 中 / 弱 / 不建议
- 推荐动作：丢弃 / 仅归档 / 只拆结构 / 只提取评论 / 深度分析 / 生成创作大纲 / 生成官号图文 / 生成博主文字脚本

### 2.2 值得学什么

从以下维度选择，并说明原因：

- 标题结构
- 封面结构
- 选题角度
- 内容展开逻辑
- 用户痛点表达
- 评论区需求
- 产品讲法
- 种草方式
- 信息密度
- 反面避坑

### 2.3 不值得学什么

必须明确指出不能学的部分，例如：

- 选题不适合小羊森林。
- 产品承接牵强。
- 标题党但内容承接弱。
- 依赖强人设，品牌号难复刻。
- 数据好但购买信号弱。
- 表达有医疗化或夸大风险。
- 评论热闹但无真实需求。
- 视频成立，但图文不一定成立。
- 图文成立，但博主口播不一定成立。

### 2.4 初筛结论格式

```txt
结论：保留 / 暂存 / 丢弃
样本池：具体分类
核心学习点：1-3 条
不建议学习点：1-3 条
产品承接判断：关联产品 + 承接强度 + 原因
推荐下一步：只拆结构 / 深拆 / 转译大纲 / 官号图文 / 博主文字脚本 / 不转译
```

## 3. 深度分析模板

只有通过初筛的样本才进入深度分析。

### 3.1 样本基本信息

- 来源类型：市场参考 / 达人合作 / 官号发布 / 用户原声 / 跨领域参考
- 作者 / 账号：
- 内容形式：图文 / 视频 / 未识别
- 发布时间 / 收录日期：
- 标题：
- 链接：
- 基础数据：点赞 / 收藏 / 评论 / 曝光 / 商品点击 / 订单 / GMV
- 当前信息完整度：完整 / 缺评论 / 缺数据 / 缺产品信息 / 缺上下文

### 3.2 内容价值判断

用等级判断，不做复杂总分：高 / 中 / 低 / 不适用 / 暂不判断。

- 流量价值：是否容易吸引点击或推荐
- 收藏价值：是否有清单、标准、方法、判断依据
- 评论价值：是否引发真实问题或讨论
- 购买信号：是否有人问链接、价格、品牌、适用年龄、怎么买
- 结构价值：是否有可迁移的标题、封面、内容逻辑
- 产品承接价值：是否能自然关联小羊森林产品
- 创作价值：是否能转译成大纲、图文或脚本
- 反面价值：是否能帮助避坑

### 3.3 爆点来源

判断它为什么可能有效：

- 选题击中高频痛点
- 标题有强钩子
- 封面信息组织清楚
- 第一段 / 第一页承接强
- 内容结构清单化
- 反常识或纠错感强
- 场景真实
- 用户身份明确
- 评论区购买信号强
- 产品出现自然
- 达人人设带来信任
- 热点 / 季节 / 节点加成

必须说明：这个爆点是可迁移的，还是依赖特定达人、热点或场景。

### 3.4 内容结构拆解

图文样本重点拆：

- 标题公式
- 封面信息结构
- 第一页 / 第一段如何承接
- 中间如何展开
- 产品或观点什么时候出现
- 最后如何收口
- 正文和评论区如何补充

视频样本重点拆：

- 开头钩子
- 前 5 秒用户为什么继续看
- 主体口播逻辑
- 场景如何建立信任
- 产品如何带出
- 结尾如何引导
- 评论区如何承接

不要做导演式分镜，不要每几秒镜头说明。

## 4. 产品承接判断规则

每条样本都必须判断是否能被小羊森林产品承接。

### 4.1 承接强度

#### 强承接

样本背后的用户需求和某个产品核心场景高度一致。

示例：

- 孩子反复积食、消后养护 → 四神饮
- 鼻炎发作期、早起喷嚏、清水鼻涕 → 玉屏乌梅饮
- 鼻炎反复、发作后体质底子 → 桃苓玉屏膏
- 夏季清润、补津、睡不踏实一头汗 → 乌梅三豆饮
- 冷饮后肚肚不舒服、夏季暖中 → 紫苏桃子汁

#### 中承接

样本需求相关，但需要换角度，不能直接照搬。

示例：

- 健康零食清单 → 可以承接四神饮，但要从“儿童加餐选品标准”切入。
- 早餐 / 加餐场景 → 可以承接食养饮品，但不能硬说解决全部问题。

#### 弱承接

只有外围关系，可以借结构或表达，但不建议强行带产品。

示例：

- 孩子一日三餐安排 → 可能和脾胃有轻微关系，但不应大量硬接四神饮。
- 母婴生活方式内容 → 可以借场景，不一定能带产品。

#### 不建议承接

样本需求和产品无关，或强行关联会显得硬蹭、违规、夸大。

示例：

- 医疗治疗场景
- 发烧、鼻窦炎、黄浓鼻涕、严重头痛
- 新闻惨剧
- 情绪热点
- 与产品场景无关的泛育儿内容

### 4.2 产品承接输出格式

```txt
可承接产品：
承接强度：强 / 中 / 弱 / 不建议
承接理由：
不能硬说的点：
建议切入角度：
不建议切入角度：
```

## 5. 产品创作承接卡

产品资料库不应该只存长文本。每个产品要整理成“创作承接卡”。

### 5.1 产品卡字段

- 产品名称
- 产品定位
- 适用年龄
- 核心使用场景
- 目标用户
- 用户痛点
- 主卖点
- 配方 / 成分表达
- 口感 / 使用便利性
- 常见顾虑
- 可承接内容方向
- 不适合硬蹭方向
- 禁用表达
- 与其他产品区别
- 适合官号图文的讲法
- 适合博主文字脚本的讲法
- 常见评论区答疑口径

### 5.2 产品卡作用

AI 后续判断样本时，必须基于产品卡判断：

- 能不能承接
- 承接哪个产品
- 该怎么承接
- 哪些话不能说
- 这个方向适合官号还是博主
- 用户顾虑应该在正文、脚本或评论区怎么处理

## 6. 评论区分析规则

评论区不是补充资料，而是判断证据。

### 6.1 评论分类

- 情绪评论：好可爱、收藏了、哈哈哈。
- 购买问询：怎么买、有没有链接、多少钱、哪个牌子。
- 适用人群问题：几岁能喝、一岁能不能喝、鼻炎能不能喝、积食期能不能喝。
- 使用顾虑：甜不甜、孩子爱不爱喝、会不会太凉、有没有添加。
- 价格 / 链接问题：有没有优惠、哪里买、怎么买划算。
- 内容共鸣：我家也这样、最近正好需要。
- 反对意见 / 质疑：是不是智商税、真的有用吗、这不就是饮料吗。
- 新选题机会：那便秘怎么办、鼻塞睡不好怎么办、积食好了还要不要养。

### 6.2 评论区重点判断

评论区分析必须输出：

- 高价值评论原话
- 用户真实需求
- 购买意向强弱
- 主要顾虑
- 能转成选题的问题
- 能转成封面句的问题
- 能转成置顶评论的问题
- 是否说明这条内容有商业价值

### 6.3 评论区价值等级

- 强：大量购买问询、适用问题、真实顾虑
- 中：有部分需求和共鸣，但购买信号不强
- 弱：主要是情绪评论
- 无：评论少或无有效信息

## 7. 创作出口

系统最终不是只输出官号图文，而是三个出口。

### 7.1 创作转译大纲

这是最核心、最常用的输出。

适合场景：

- 样本有价值，但还没决定做图文还是视频。
- 用户想先判断这个点能不能用。
- 需要先形成内容方向，再决定后续细化。

输出结构：

1. 可用方向一句话
2. 关联产品
3. 用户需求
4. 切入角度
5. 标题方向
6. 内容主线
7. 产品进入方式
8. 可借鉴表达
9. 不可照搬部分
10. 推荐出口：官号图文 / 博主文字脚本 / 两者都可 / 暂不建议

### 7.2 官号挂车图文

适合品牌官方账号。

输出结构：

- 标题候选
- 封面文案
- 第一页承接
- 内页结构
- 产品出现位置
- 每页内容要点
- 正文
- 话题标签
- 置顶评论
- 合规风险提醒

注意：

- 封面不堆长句。
- 标题和封面不重复。
- 产品出现要有理由。
- 不写治疗、根治、立刻见效。
- 正文不复述图文，要补卖点、吃法、注意事项和关键词。

### 7.3 博主文字脚本

适合给达人 / 博主使用。

不叫达人 brief。
不写分镜。
不写导演式拍摄指导。
不写每几秒镜头。

输出结构：

- 视频主题
- 开头钩子
- 完整口播脚本
- 产品自然带出段
- 用户顾虑补充段
- 结尾收束
- 评论区引导
- 可删减版本
- 风险提醒

核心要求：

- 博主看了就知道怎么讲。
- 逻辑完整。
- 不像品牌硬广。
- 产品出现自然。
- 不过度承诺效果。

你不要默认这条样本有价值，也不要默认它一定要被复刻。

请先做样本初筛，判断它是否值得保留、值得学什么、不值得学什么、能否被小羊森林产品承接，以及是否需要进入下一步创作转译。

请按以下结构输出：

1. 样本是否值得保留：保留 / 暂存 / 丢弃

5. 值得学习的部分：1-5 条，说明具体原因
6. 不值得学习的部分：1-5 条，说明具体原因
7. 评论区价值：购买问询、适用问题、使用顾虑、新选题机会；没有评论则说明无法判断
8. 推荐动作：丢弃 / 仅归档 / 只拆结构 / 只提取评论 / 深度分析 / 生成创作大纲 / 生成官号图文 / 生成博主文字脚本
